# higher-education-iam-modernization
Enterprise IAM modernization using Microsoft Entra ID, Azure, and identity governance

Overview

This project demonstrates the design and implementation of an Identity and Access Management (IAM) solution for a simulated higher education institution using Microsoft Entra ID.

The environment represents a university supporting faculty, staff, students, IT support personnel, privileged administrators, and third-party contractors.

The objective is to establish a secure identity foundation supporting account provisioning, access management, least privilege, identity lifecycle management, and centralized governance.

Technology Stack

- Microsoft Entra ID
- Microsoft Azure
- Identity and Access Management (IAM)
- Security Groups
- Role-Based Access Control (RBAC)
- PowerShell and Microsoft Graph (planned)

Project Phases

| Phase | Description | Status |
| 01 | Identity Foundation & Account Provisioning | In progress |
| 02 | Identity Lifecycle Management | Planned |
| 03 | RBAC & Least Privilege | Planned |
| 04 | Identity Security & Access Policies | Planned |
| 05 | Identity Governance & Monitoring | Planned |

Environment

- Personal Microsoft Entra tenant
- Microsoft Entra ID Free
- Cloud-only synthetic test identities
- Assigned security group membership

Security Considerations

- Synthetic identities only.
- No production credentials or sensitive information.
- Least-privilege design principles.
- Privileged identities modeled separately from standard users.

Project Goal

Develop practical cloud identity engineering skills through hands-on implementation, validation, automation, and technical documentation.

This is a simulated portfolio environment, not a production university deployment.
